# Glossly

Highlight text anywhere on Windows and act on it: ask about it, save it, reply to it, see who's in it, pull out promises, or chart it.

- Status for humans: [`STATUS.md`](STATUS.md)
- Start here if you're working on it: [`docs/HANDOFF.md`](docs/HANDOFF.md) (state, next steps, environment), then [`docs/architecture.md`](docs/architecture.md), [`docs/features.md`](docs/features.md), [`docs/decisions.md`](docs/decisions.md), [`docs/testing.md`](docs/testing.md)
- The original spec: [`docs/Highlight-to-Action App Prototype Spec.md`](docs/Highlight-to-Action%20App%20Prototype%20Spec.md)

```powershell
pnpm install
pnpm dev     # needs Node 24, pnpm 12, and the .NET 10 SDK on Windows 11
pnpm test
```
