# Design mockups

The HTML mockups Rayan reviewed before each part of Step 20 was built (decisions 38 to 40). They load the app's real `theme.css` and `controls.css` from `packages/ui/src`, so open them from this folder in a browser (the stylesheets are linked by relative path); everything in them is clickable. All people and data in them are fictional.

| File | What it settled |
| --- | --- |
| `mockups/20-1-design-system.html` | Our own controls, the spacing scale, buttons, monochrome (decision 39). |
| `mockups/20-2-tasks-calendar.html` | The Tasks and Calendar tabs, drag gestures, glass events (decision 40). |
| `mockups/20-3-design-pass.html` | Keyboard hints, the setup redesign, app icon options, motion (Step 20.3). |

They show the state Rayan approved; the app may have moved on since. The app icon candidates are also in `docs/brand/` as SVG files.
