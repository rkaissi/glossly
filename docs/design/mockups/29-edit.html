Edit

Step 29 proposal: change the text you selected, in place

Select text in a field you can type in, and the bar offers Edit. Its panel has a box for any change and buttons picked for this text. The result shows with its changes marked, and Enter puts it in place of the selection. Nothing in the field changes until you press Replace. All people, companies, and text below are made up.

1. When Edit shows up

A selection in a field you can type in gets Edit in slot 3. Ask and Save keep 1 and 2, and slot 4 is still the router's pick. With nothing selected the bar works as it does today, so Write here and Edit are never on the bar together.

Your own draft selected in a reply box

  • Slot 4 here is Tasks because the draft promises "I'll send it Friday". Without a promise it's whatever the router picks, or nothing.

Nothing selected, caret in the same box

  • As today (decision 82). Edit needs a selection, so it isn't here.

Their quoted email selected inside your reply

  • The field is editable, but the text has a quote header ("On Tue, Jordan Hale wrote:") or > lines, so it's someone else's message: Reply wins slot 3.

A message selected on a page you can't type in

  • Edit is only under More here, and its result can be copied, not put back.

2. Opening Edit

The panel opens at once with the rule buttons. One quick model call adds up to two buttons made for this text (dashed). They appear a moment later, and the rule buttons never wait for them.

Re: Northwind invoice · Mail
hey Casey, thanks for the reciept. Ill send the signed copy to Northwind tommorow, sorry for the delay

Edit your text · 17 words

Describe a change…
Tab buttons · Enter run · Esc back

How the buttons were picked

  • Fix comes first. It opened as "Fix 3 typos": the spellchecker found "reciept", "Ill", and "tommorow". It also flagged "Northwind" and "Casey", but they're saved names (an entity and a person), so they don't count. A moment later the model counted one grammar problem (the run-on before "sorry"), so it now reads "Fix 4 mistakes". With no typos and no grammar problems there's no Fix button at all; with grammar problems only, it's "Fix grammar".
  • Rewrite, Shorter, Friendlier, More formal are always there for prose.
  • Give a time (dashed) is the model's idea for this text: "tomorrow" with no time, in a promise.
  • The box takes anything: "say it was my fault", "in French", "as bullet points".

3. Fix: the changes, marked

A fix shows every change in place: the old word struck out, the new one highlighted. Enter replaces the selection in your field.

Change it more…
Enter replace · Esc back
  • A fix changes as little as it can and keeps your casual tone ("hey" stays). It runs on the quick model, so it's back in about a second.
  • The marks are only in the panel. Replace puts in the clean text.
  • "Left alone" shows when a flagged word was skipped because it's a name, so you can see why it wasn't touched.
  • Buttons under the result change it again on top of the fix (section 5).

5. Changes on top of changes

Each button or typed request applies to the latest result. A trail of steps sits above it, and clicking an earlier step goes back to it.

›››
Hi Casey, thanks for the receipt! Signed copy goes to Northwind tomorrow. Sorry for the wait.
Change it more…
Enter replace · Alt+← step back
  • Steps stay until the panel closes. Switching to another slot and back keeps them, like Write here's cached text.
  • After Shorter, the buttons swap to fit: Longer appears, Shorter goes.
  • Typed requests and tone buttons teach your style, like Write here's (when "Learn as I write" is on). Fixes teach nothing.

6. Write this out: an instruction or a placeholder

When the selection reads like a note to yourself ("tell…", "write…", "[pricing here]", "TODO: …"), Edit's first button writes the real text from what you saved, the way Write here does, with the same Used chip.

#acme-launch · Chat
tell jordan the deck slips to friday, nicely

Write this out · to Jordan

Hey Jordan, quick heads-up: the Acme deck needs a little more time, so I'll have it to you Friday instead of Wednesday. That still leaves the weekend before Monday's review. Thanks for bearing with me!
Used 1 task · 1 event · Jordan
Enter replace
  • Write this out runs on its own when the whole selection is an instruction, since there's nothing to fix. A placeholder inside longer text ("…pricing: [table here]") gets it as the first button instead.
  • It knew "Wednesday" and "Monday's review" from the saved task and event, like Write here. Without saved matches it writes from the instruction alone.
  • This is the one selection case Write here used to cover, so the two never compete.
